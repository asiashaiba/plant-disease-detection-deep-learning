# 🌱 Plant Disease Detection Using Deep Learning

A deep learning-based project that detects and classifies plant diseases from leaf images.

## 📌 Project Overview

Plant diseases can negatively affect crop health and agricultural productivity. This project uses deep learning and image classification to identify plant diseases from images of plant leaves.

The model is trained on a dataset of plant leaf images and learns to classify the images into their corresponding disease categories.

## 🎯 Objectives

- Detect plant diseases from leaf images
- Preprocess and prepare image data for model training
- Train a deep learning image classification model
- Evaluate the model's performance
- Predict the disease category for new leaf images
